## Defects found and fixed

### Type narrowing and lint failures

The first typecheck reported that the follow-up action had widened to `string`, and test params inferred optional `undefined` values. ESLint also rejected a `useMemo` whose dependency list was narrower than the object read by the callback. The fixes were an explicit `AccountFollowUp | undefined` contract, a concrete `Record<string, string>` and removal of unnecessary memoization. Typecheck and lint then passed.

### Success message lost after create

The profile was saved correctly, but the editor key changed from `create` to the new record version. React unmounted the editor, so its local success message disappeared immediately. Success feedback was moved to the stable page-level ToastProvider; field errors remain local. Browser replay confirmed the toast remains visible.

### Test locator ambiguity

The page has a header “Thêm nhân viên” button and a form submit button with the same visible name. An unscoped browser locator correctly failed strict mode. The test was repaired by scoping the submit locator to `#employee-editor-start`; product semantics remained unchanged.
